# 使用说明

wt-go 是一个 Windows Terminal 风格的终端：多标签、分栏、profile、配色方案与可录制快捷键。
`settings.json` 全字段与键位写法见 [配置参考.md](配置参考.md)，诊断与故障码见 [故障排查.md](故障排查.md)。

## 1. 运行方式与便携模式

- **Windows 10 1809+ / 11**：主要支持与验证目标，通过 ConPTY 启动 shell。
- **Linux / macOS（实验性）**：有 pty 与平台路径实现；Linux 运行依赖见 [README](../README.md)，已知限制见第 8 节。

启动时可用 `-d <目录>`（或 `--dir <目录>`）仅替本次运行覆盖 `startDirectory`（`home` / `current` / 具体路径；profile 自带的 `dir` 仍优先）：

```pwsh
wt-go.exe -d D:\work
wt-go.exe -d home
```

**便携版 vs 安装版**（以 exe 同目录是否存在名为 `data` 的目录判定）：

| 模式 | 设置与窗口状态 | 运行日志 | 崩溃日志 |
| --- | --- | --- | --- |
| 便携版（存在 `data` 目录） | `data\config\settings.json`、`window-state.json` | `data\logs\wt-go.log` | `data\crashes\crash-*.log` |
| 安装版（无 `data` 目录） | `%LOCALAPPDATA%\wt-go\`（Linux `~/.config/wt-go/`） | 同目录 `wt-go.log` | 同目录 `crash-*.log` |

- 发布包自带 `data\README.txt`（解压即便携版）与 `conpty\`（Windows Terminal 同源 ConPTY，使终端内程序询问的配色、深浅色与鼠标能正确回传）。
- 仅单独复制 `wt-go.exe` 而不带 `data\` 与 `conpty\` 也能运行：配置回落至安装版目录，Windows 终端退回系统 conhost（部分程序颜色/鼠标询问无回复，可在 `wt-go diag` 的 `portable:` / `conpty:` 与「关于」页确认）。

## 2. 窗口与标签

标签栏兼作标题栏（40 DIP），空白处可拖动窗口、双击切换最大化、右键打开窗口菜单（还原/最小化/最大化/关闭/设置）。

- **活动标签**与下面窗格共用终端底色并带圆角，未激活标签名字仍用正文色、仅色块淡一档。
- **标签前缀方块**：终端标签显示 profile 颜色方块与记号（自动随亮度切换深浅前景）；设置页为强调色配齿轮图标。
- **固定功能区**：`+` 与 `▾` 紧跟末尾标签；标签溢出时固定在右滚动按钮 `❯` 旁，右侧保留固定拖窗空白。

| 操作 | 方式 |
| --- | --- |
| 新建标签 | `Ctrl+Shift+T` / `Ctrl+T`、标签条 `+`、右键菜单 |
| 用指定 profile 新建 | 标题栏 `▾` 菜单、`Ctrl+Shift+1`…`Ctrl+Shift+9` |
| 切换标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab`、`Ctrl+1`…`Ctrl+9`、点击、`Ctrl+滚轮` |
| 关闭标签 | 标签 `×`、中键点击、右键菜单（受 `confirmClose` 约束） |
| 重命名 / 置色 | 标签右键菜单（设置标签页无重命名/复制） |
| 拖拽排序与滚动 | 按住标签左右拖动排序；溢出时出现 `❮`/`❯`，支持滚轮横向滚动 |
| 新标签位置与宽度 | `newTabPosition`（`last`/`first`）；`tabWidth`（`compact`/`equal`） |

关闭带有 **2 个及以上**标签的窗口时（点 `×` 或 `Alt+F4`），若 `confirmCloseWindow` 开启（默认）会先确认一次；只剩 1 个标签或由「删除设置并重启」触发时不重复询问。

所有弹出菜单（标签右键、`▾`、终端右键、标题栏菜单）均画在窗口内并使用窗口主题色，支持键盘上下、回车、`Esc` 与首字母导航。「关于」弹窗展示版本、提交、运行时、运行方式、所用 `conpty.dll`、设置/日志路径及可点击打开的项目主页。

## 3. 分栏与快捷键

每个标签是一棵窗格树，最多 `maxPanes` 个窗格（默认 4，`0` 为不限）：

| 操作 | 默认快捷键 |
| --- | --- |
| 自动切分（先竖后横）/ 纵向 / 横向 | `Alt+Shift+D` / `Alt+Shift+Right` / `Alt+Shift+Down` |
| 焦点移到相邻窗格（按矩形几何匹配） | `Alt+方向键` 或点击 |
| 关闭当前窗格 / 关闭其它窗格 | `Ctrl+Shift+W` / `Alt+Shift+W` |
| 调整分栏比例 | 拖动分割线（每格最小 40 DIP） |

常用全局键：`Ctrl+,` 打开设置、`Ctrl+Shift+F` 查找、`Ctrl+Shift+P` 命令面板。按住按键不放时，仅「走一步」动作（`tab.next`/`tab.prev`、`pane.focus.*`）连发，新建标签等动作只执行一次。完整默认键位与自定义写法见 [配置参考.md](配置参考.md)。

## 4. Profile 与默认配置文件

- **探测机制**：仅在首次创建 `settings.json` 时扫描本机可用 shell 并写入 `profiles`（带「内置」标签）。之后 `settings.json` 为唯一来源，不会在启动时覆盖用户修改。
  - Windows：按 PATH 扫描 `pwsh.exe`、`powershell.exe`、`bash.exe`（跳过 WSL 转发壳 `System32\bash.exe`）、`cmd.exe`、`nu.exe` 及注册表 WSL 发行版（跳过 `docker-desktop` / `docker-desktop-data`）。
  - POSIX：读取 `$SHELL`、`/etc/shells` 中常见 shell，最后 `/bin/sh` 兜底。
- **编辑、隐藏与重置**：
  - 内置条目在设置页中 `command` 只读，可改名、改颜色、改图标与目录；提供「隐藏」与「重置为内置」（仅按当前机器重探这一条，保留 `dir`）。
  - 自定义条目可删除或隐藏；所有隐藏条目仍列在设置页左栏（带「已隐藏」徽标），取消隐藏即可恢复，但不出现在 `▾` 菜单与默认配置下拉中。
  - **标签图标（`icon`）**：支持跟命令自动识别、12 套内置图形或任意单字符/emoji；保存后已开标签实时更新。
- **默认配置文件（`defaultProfile`）**：留空即为「跟随设备」，按固定顺序取每次启动实测到的第一个本机 shell（`pwsh7` → `powershell` → `bash` → `cmd` → `nu` → `wsl:*`），不读取已隐藏条目。它决定首个标签、`Ctrl+T`/`Ctrl+Shift+T`、`+` 与空窗口提示开哪个 profile；`Ctrl+Shift+D` 复制标签与切分窗格沿用当前标签的 profile。
- **标签标题优先级**：手动重命名 > shell 设置的非路径标题 > profile 名 > 标题中提取的程序名 > 启动的 shell 名 >「跟随设备」。

## 5. 主题、配色方案与设置页

- **界面主题与终端配色分离**：`theme`（`system`、`light`、`dark` 或任意配色方案名）控制标签栏、对话框、滚动条等窗口外观；`colorScheme`（自定义 `schemes` > 内置 7 套 > Ghostty 617 套 > `theme` 对应默认色）控制终端网格。二者互不影响，仅活动标签跟随当前窗格底色。
- **自定义配色**：在「外观与排版」点击「复制为自定义配色」可在 `schemes` 生成副本并自动去重命名（`Base (custom N)`），列表行尾 `×` 可删除自定义方案。
- **设置页（`Ctrl+,`）**：
  - 顶部搜索框按名称、页面与常用关键词跨页检索；六大页面为「常规与启动」「终端与交互」「外观与排版」「配置文件」「快捷键」「高级与系统」。
  - **实时生效**：语言、主题、配色、字体排版、透明度、置顶、选中即复制、滚轮倍数、链接及其三项来源开关与悬停高亮、键位与标签图标；**新标签/窗格生效**：内边距与填充色、光标形状与闪烁、回滚缓冲、右键菜单、剪贴板权限。
  - **校验与热重载**：表单实时预览，点击「保存」先按范围校验（不通过时顶部保留红色错误横幅且草稿不丢失）；后台每秒热重载文件，有未保存草稿时不会覆盖，外部已修改时拒绝直接覆写。
  - **快捷键页**：列出动作目录全部动作，以动作 id 为键、单动作只保留一个录制键，冲突时整行标红，编号动作默认折叠至前 3 项。
  - **高级页**：「重新探测」（重写内置条目命令行，保留名字/颜色/目录）、「删除设置并重启」、打开设置/程序目录。

## 6. 查找、链接与命令面板

- **查找（`Ctrl+Shift+F`）**：忽略 ASCII 大小写，`Enter` 下一个、`Shift+Enter` 上一个、`Esc` 关闭并清除高亮，显示 `当前 / 总数`。
- **链接（`links`，一组四个开关）**：**点击打开**，按住拖动则选中文本不打开。链接有三类来源，各自开关：
  - `links.program`（默认开）：程序自己设置的超链接（OSC 8）；
  - `links.url`（默认开）：程序打印出来的网址（`http://`、`ftp://`、`mailto:`），用系统默认浏览器打开；
  - `links.path`（**默认关**）：终端猜出来的输出路径（带扩展名或斜杠的词，自动去掉 `:行` / `:行:列` 后缀），用桌面关联程序打开。默认关是因为这个猜测会让指针在普通输出上乱亮；打开后相对路径优先按 shell 通过 OSC 7 报告的目录解析，Windows PowerShell 默认不报则退回窗格启动目录，路径不存在时不操作，打开失败记 `E209`。
  - `links.hover`（**默认关**）：指针停在链接上就画下划线并变成手型；关着时按住 `Ctrl` 才算链接（Ghostty 的做法）。程序接管鼠标（vim、htop 等）时不高亮，那儿的点击归程序。
  - `links.open`：以上三类与悬停的总开关，关掉立即取消下划线与点击。
- **命令面板（`Ctrl+Shift+P`）**：模糊搜索全部动作（含快捷键）、已开标签与可用 profile；内置「帧率」命令可在右下角开关最近 240 帧的帧率与最长帧耗时读数。

## 7. 与 Windows Terminal 的主要差异

- `settings.json` 采用扁平结构，不兼容 WT 的 `profiles.list` / `actions` / `defaults.json` 两层合并；`rightClick` 的忽略项名为 `nothing`（非 `ignore`）；`language` 使用 BCP 47 标签（`zh-Hans` / `en` / `""`，可兼容读取 `zh-CN` / `en-US`）。
- 终端链接默认按住 `Ctrl` 才高亮（`links.hover` 打开后与 WT 一样悬停即高亮），点击打开无需 `Ctrl`；链接路径类来源默认关闭（`links.path`，WT 默认开启）；相对路径暂不支持 PowerShell 的 OSC 9;9。
- 字体为全局配置（无 per-profile 独立字体）；暂未实现会话恢复（`startOn: restore`）、标签搜索、窗格缩放/交换/广播输入、背景图与亚克力/CRT 效果。

## 8. Linux 已知限制（实验性）

- **标题栏按钮**：遵循 `gtk-decoration-layout`；当该值为空（常见于平铺 WM）或由合成器接管标题栏（KWin/Hyprland/Sway Wayland）时不绘制窗口按钮，窗口操作走快捷键或 WM。Wayland 下 `alwaysOnTop` 受合成器限制可能无效；主进程被 `kill -9` 时子 shell 可能残留一次。
- **文字颜色保护**：启动时向内存 fontconfig 追加 `rgba=none` 规则，避免 cairo 将次像素抗锯齿误判为彩色字形导致文字发白发绿（代价是退回灰度抗锯齿）。
- **输入法与后端**：中文输入需设置 `GTK_IM_MODULE`（如 `fcitx` 或 `ibus`）；必要时可用 `GDK_BACKEND=x11` 切换后端。
