# 键位

快捷键怎么改、默认值是什么、`keybindings` 里的字符串怎么写。
动作 id、标题、分组与默认键位只有一份，在 `internal/action/action.go`：菜单、命令面板、
设置页的「操作」分组都从它取，所以这里列的就是程序里的那一份。

## 1 默认键位

默认值与 Windows Terminal 对齐。设置页「操作」分组把动作目录里的每一条都列出来，
没有默认键的动作（「关闭标签」）也在里面，显示为 `无`，点一下就能给它分配一个键。

标签（`Tab`）：

| 键 | 动作 id | 动作 |
| --- | --- | --- |
| `Ctrl+Shift+T`、`Ctrl+T` | `tab.new` | 新建标签 |
| `Ctrl+Tab` | `tab.next` | 下一个标签 |
| `Ctrl+Shift+Tab` | `tab.prev` | 上一个标签 |
| `Ctrl+Shift+D` | `tab.duplicate` | 复制当前标签 |
| `Ctrl+1`…`Ctrl+9` | `tab.goto.N` | 切到第 N 个标签 |
| `Ctrl+Shift+1`…`Ctrl+Shift+9` | `profile.N` | 用第 N 个 profile 新建标签 |
| （无） | `tab.close` | 关闭标签 |

窗格（`Pane`）：

| 键 | 动作 id | 动作 |
| --- | --- | --- |
| `Alt+Shift+D` | `pane.split.auto` | 自动切分（先竖后横） |
| `Alt+Shift+Right` | `pane.split.right` | 纵向切分（左右） |
| `Alt+Shift+Down` | `pane.split.down` | 横向切分（上下） |
| `Alt+左/右/上/下` | `pane.focus.left` / `right` / `up` / `down` | 焦点移到相邻窗格 |
| `Ctrl+Shift+W` | `pane.close` | 关闭窗格（最后一个窗格时关标签） |
| `Alt+Shift+W` | `pane.closeOthers` | 关闭标签内其它窗格 |

窗口（`Window`）：

| 键 | 动作 id | 动作 |
| --- | --- | --- |
| `Ctrl+,` | `settings.open` | 打开设置 |
| `Ctrl+Shift+P` | `palette.open` | 命令面板 |
| 没有默认键位 | `about.open` | 关于：标题栏 `▾` 菜单最下面，或从命令面板打开；要键位就在设置页「操作」里录一个 |

查找（`Find`）：`Ctrl+Shift+F` → `find.open`。

终端插件自带的键（未经 wt-go，由 `mygo/plugins/terminal` 处理）：

| 键 | 动作 |
| --- | --- |
| `Ctrl+Shift+C` / `Ctrl+Insert` | 复制选中 |
| `Ctrl+Shift+V` / `Shift+Insert` | 粘贴 |
| `Ctrl+Shift+A` | 全选 |
| `Ctrl+C` | 有选中时复制，否则发给程序 |
| `Ctrl+滚轮` / `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置字号 |
| `Ctrl+Shift+K` | 清屏 |
| `Shift+PageUp` / `Shift+PageDown` | 翻页 |
| `Ctrl+Shift+Home` / `Ctrl+Shift+End` | 滚到顶 / 底 |
| `F11` / `Alt+Enter` | 全屏 |
| `Ctrl+Shift+Space` | 下拉菜单 |

不在表内的键一律发给终端里的程序。要把某个默认快捷键让给程序，删掉对应的 `keybindings` 条目，
而不是写 `none` —— 现在没有透传，写 `none` 只是让那个键什么也不做。

## 2 `keybindings` 怎么写

```json
"keybindings": [
  { "key": "ctrl+shift+t", "action": "tab.new" },
  { "key": "ctrl+t", "action": "tab.new" }
]
```

- 一个动作可以写多个键（上例给 `tab.new` 两个键）；写两次同一个键不算冲突。
- **整张表取代默认值**：文件里写了 `keybindings`，默认键位就全部不生效，不是"在默认之上叠加"。
- 默认键位会随版本增加，已存在的 `settings.json` 自带完整列表，**不会自动获得新默认键位**；
  需要的话在设置页点「恢复默认」，或删掉这个字段让程序重新生成。
- 写了未知动作或解析不了的按键，该条不执行动作，但**未知动作仍可能接管那个按键**。
  要把按键交给终端，请删掉该条。
- 在设置页「操作」分组里录一个键，改的是**内存里的草稿**，点「保存」才写进文件；
  与其它动作冲突时那一行标红（格子里列出该动作当前的全部键，`ctrl+shift+t · ctrl+t`）。
  界面**一个动作只写一个键**：录新键会把该动作原来的键（可能有两个）一起删掉；
  想一个动作跑两个键，就在文件里手写。「删除」把一个动作的键位全部去掉，
  「重置」把它改回默认键。

## 3 动作名

`tab.new`、`tab.close`、`tab.next`、`tab.prev`、`tab.duplicate`、`tab.goto.N`（N 从 1 到 9），
`pane.split.auto`、`pane.split.right`、`pane.split.down`、`pane.focus.left`、`pane.focus.right`、
`pane.focus.up`、`pane.focus.down`、`pane.close`、`pane.closeOthers`，
`find.open`、`palette.open`、`settings.open`、`profile.N`（第 N 个 profile，按菜单顺序，N 从 1 到 9）。

## 4 键位字符串

修饰键 `ctrl`（也认 `control`）、`shift`、`alt`、`win`（也认 `super`/`meta`/`cmd`/`command`），
键名小写（整串不区分大小写）：

- `a`–`z`、`0`–`9`、`f1`–`f12`；
- `tab` `enter` `escape` `space` `backspace` `delete` `insert` `home` `end` `pageup` `pagedown`
  `up` `down` `left` `right`；
- 标点：`minus` `equal` `comma` `period` `slash` `semicolon` `quote` `backslash`；
- 别名：`return`（= `enter`）、`esc`（= `escape`）、`del`、`ins`、`pgup`、`pgdn`。

`plus` 与 `f13` 以上暂不支持。解析不了的那条会被丢弃，日志里有一行 `E203` 指向原文，
对应动作**不会**退回它的默认键（见 [故障排查.md](故障排查.md)）。
