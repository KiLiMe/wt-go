# 实现计划

原则：每个阶段都能**独立运行、可验收**，不在半成品上叠功能。
先保证"开一个窗口、敲命令、复制粘贴、关得掉"，再谈像不像 Windows Terminal。

---

## 阶段 0：骨架（打通 mygo + terminal）

**做什么**

1. `go.mod`（module `wtgo`，`go 1.27.3`，依赖 mygo v0.8.3）。
2. `main.go`：`mygo.App.WhenReady` → `terminal.New()` → `NewWindow`。
3. 单标签、单窗格，`terminal.View(...).Fill().AutoFocus()` 占满。
4. 窗口标题跟随 shell 的 OSC 0/2；进程退出时标签显示"已退出"，窗口不自动关。

**验收**

- 打开就是 pwsh 7，能跑命令、显示中文和 emoji、颜色正确。
- 关掉 shell（`exit`）后窗口仍保持打开，窗口标题显示已结束及退出码。
- 新建标签及标签栏属于阶段 1，不作为阶段 0 的验收条件。

**风险**：`mygo build` 打包 libghostty-vt 原生库；`go run` 能否直接加载需先验证。

## 阶段 1：标签与 profile

**状态**：已完成（2026-11-10）。

**做什么**

1. 标签栏：新建、关闭、切换、重命名、拖拽排序。
2. profile 模型：名字、program、args、起始目录、字体/主题覆盖、图标色。
3. 默认 profile 自动发现：pwsh 7 / Windows PowerShell / cmd / WSL 发行版（读注册表）。
4. 标签栏尾部 `+`（新标签用默认 profile）与 `▾`（下拉选 profile）。
5. 右键标签：重命名、复制标签、关闭、关闭其它。

**验收**：同时开 pwsh、cmd、wsl 三个标签，各自的标签名和图标区分清楚；
关闭最后一个标签时窗口关闭（可配置为不关）。

**实际结果**：标签栏兼作标题栏（36dp，与 WT 一致），激活标签用终端背景色 + 上圆角；
标签名取“重命名 > 程序标题 > profile 名”，程序把自己的标题设成 exe 路径时不显示路径。
已知退化：标签多到放不下时不会横向滚动（为留出右侧拖窗空白区），待做文本测量后再补。

## 阶段 2：分栏

**做什么**

1. 窗格树：一个标签内可横向/纵向切分，最多 `maxPanes` 个（默认 4，0 为不限）。
2. 快捷键：`Alt+Shift+D` 自动切、`Alt+Shift+Right` 竖切、`Alt+Shift+Down` 横切。
3. 焦点移动：`Alt+方向键`；关闭窗格 `Ctrl+Shift+W`（焦点窗格，最后一个窗格时关标签）。
4. 分割线可拖动调整比例；关闭窗格后兄弟窗格补位。

**验收**：4 窗格内各自跑不同程序，缩放窗口后布局与终端尺寸都正确。

**状态**：已完成（2026-11-10）。

**实际结果**：窗格树在 `internal/pane`（`Tab`/`Node`），几何在 `internal/layout`；自动切分方向看焦点窗格的矩形（高 > 宽就横切）；焦点移动按几何判定（同方向、跨度重叠最多者优先）；窗格上限由 `app` 按 `maxPanes` 拦。
已知取舍：键盘焦点靠每帧 `Element.Focus()` 保持（`AutoFocus` 只在一帧生效），对话框打开时让给对话框；分割线的拖动热区是 8dp 宽（线本身 4dp）。

## 阶段 3：设置界面与配置文件

**状态：已完成（2026-11-10）。**

**已提前落地**（阶段 1/2 期间）：`colorScheme`/`schemes`（含 Ghostty 617 套与自定义覆盖）、`backgroundOpacity`（窗口整体透明度）、`font`、`padding`、`cursorShape`/`cursorBlink`、`scrollbackMB` 已生效。

**做什么**

1. **设置标签页**：`Ctrl+,` 打开，当作普通标签（名称 + 关闭按钮；当前暂无齿轮图标），左栏分组导航、右侧表单、底部「保存 / 放弃更改」；有未保存改动时关标签要提示。
   - 左栏：启动、交互、外观、配色方案、操作；然后是「配置文件」组（默认值 + 每个 profile + 添加新配置文件）。
   - 底部「打开 settings.json」：用系统默认程序打开配置文件。
2. **启动**：默认配置文件、语言、启动时（新标签 / 恢复上次）、启动大小（列 × 行）。
3. **交互**：选中即复制、右键行为（菜单 / 复制或粘贴 / 粘贴 / 忽略）、多行粘贴确认、`Ctrl+滚轮` 调字号、`Ctrl+Shift+滚轮` 调透明度、URL 自动识别可点击。
4. **外观**：应用程序主题（深/浅/跟随系统）、新标签位置（最后 / 第一个）、标签宽度（等宽 / 紧凑）、窗口置顶、标题跟随活动终端的标题。
5. **配色方案**：列表（内置 + Ghostty + 自定义），选中即预览（前景 / 背景 / 光标 / 16 色），「编辑」把当前方案复制成自定义项再改字段。
6. **操作**：快捷键列表（按键 → 动作），录制新键、删除、恢复默认；与已有键冲突时提示。
7. **配置文件**：默认值页（全局字体与外观）+ 每个 profile 页（名称、命令行、参数、起始目录、图标色、隐藏、删除、复制），保存写回 `profiles`。
8. **热重载**：监听 `settings.json` 外部改动，合法就应用，非法则保留旧值并在设置页提示。
9. **▾ 菜单**补「设置」，profile 项右侧显示 `Ctrl+Shift+N` 快捷键。

**实际结果**

- 设置页是「实时预览」模型：表单直接改当前设置，每帧与已应用的值比较后应用一次；「保存」写回文件、「放弃」回到文件的值；未保存时关标签先问一句。
- 配置文件的参数用多行文本框输入（一行一个），编辑的是副本，保存时才写进 `profiles`；只是看一眼不会把自动发现的 profile 落盘。
- 配色方案页除列表与预览外，提供「复制为自定义配色」：把当前方案的 20 个颜色写成一条 `schemes` 并选中它（等价于 WT 的「编辑即复制」）。
- 键位录制监听整张键名表（含 `ctrl+comma`、`f1`–`f12` 等），用 `OnWindowShortcut` 注册，所以焦点在终端里也能录。
- 「操作」页列的是动作目录的全部动作（35 行），不只是文件里已有的键位：`tab.close` 这类没默认键的动作显示「无」，点一下就能录一个键（ADR-023）。
- 紧凑模式下标签宽度用 `Context.MeasureText` 量名字，夹在 48–240，超出用 `…` 截（ADR-024）；等宽模式仍是定宽。
- `startSize` 用两次测量得到单元格尺寸（终端只报格数不报格宽），实测 100×30 准确。
- `Ctrl+滚轮` 字号以及 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 由 mygo 终端插件提供，当前已可用；`Ctrl+Shift+滚轮` 调透明度仍未做。`startOn` 只解析，恢复上次会话要等阶段 5。
- URL 识别是终端插件自带的（`OpenLink` 默认交给系统打开），不需要额外开关。

**验收**：设置页改任意项 → 保存后立刻生效并写回同一份文件；手动改文件存盘后同样生效；重启后设置保留；配色方案列表能选到 Campbell 与 Ghostty 的名字。

**本阶段新增的配置字段**：`startSize{columns,rows}`、`newTabPosition`、`tabWidth`、`alwaysOnTop`、`titleFromActiveTerminal`。

## 明确不做

- SSH / 串口 / 隧道 / 密码保管（那是 sshterm 的领域）。
- 多窗口共享会话、协作、录制。
- 插件系统（至少前三阶段不做）；WT 的「扩展」页不做。
- 命令行参数兼容 `wt.exe` 的全套（只做 `wtgo [profile] [-- dir]`）。
- WT 设置页里与渲染后端相关的整页：**呈现**（Direct2D / WARP / 交换链）。
- **兼容性**页：后台运行、文本度量模式、清缓存（只保留「重置为默认设置」按钮，放设置页底部）。
- 亚克力 / 背景图 / 通知区域图标 / 最小化到托盘 / 自动隐藏窗口 / 窗格动画。
- 标签搜索、焦点标签放大、标签切换界面样式（独立窗口那种切换动画）。
- 「新选项卡菜单」的可配置菜单树（个人资料 / 分隔符 / 文件夹 / 子菜单 / 配置匹配器）；wt-go 的 ▾ 菜单就是非隐藏 profile 列表 + 设置 / 命令面板 / 关于。
- 复制为 HTML、矩形选中删行尾空格、粘贴删尾随空格、单词分隔符、默认输入法模式、启动参数、多实例策略（新建实例行为）。
