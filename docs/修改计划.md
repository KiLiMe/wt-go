# wt-go 修改计划

基于代码审计结果，将待改进项按风险与收益分为 **P0–P3** 四个阶段。每个阶段独立可验收，不引入半成品状态。

> 约定提醒（见 `AGENTS.md`）：
> - 新增故障路径需在 `internal/fault` 编号并在 `docs/故障排查.md` 同步记录；
> - 修改包依赖需同步更新 `internal/app/deps_test.go` 与 `docs/代码导读.md`；
> - 静态文案统一使用 `locales.*` typed accessor，修改 `locales/*.json` 后跑 `go tool mygo generate` 与 `go tool mygo i18n check`；
> - 每阶段完成后跑通 `go vet ./...`、`go test -count=1 ./...`（在支持 cgo 的环境加 `-race`）与 `pwsh ./Scripts/build.ps1 -Test`。
>
> **进度标记**：`✅` 表示已按验收标准在代码与测试里落实（下面只写现状，不写未做的）；
> 未标的一律视为待办，哪怕代码里已有一部分。

## P1：架构与状态收敛（降低 `internal/app` 复杂度）

目标：拆分过载文件，消除隐式时序依赖与草稿/生效状态耦合，统一规范落地。

1. **拆分 `internal/app` 大文件（保持包内结构清晰）**
   - 抽出 `internal/app/watcher.go`：承接 `watch`、`poll`、`reload`、`fileState`、`apply` 与 `configErr`/`badData` 状态机；修复 `poll` 与 `reload` 之间的 `markSeen` 竞态（仅在 UI 线程或持有单调版本/时间戳时更新 `seen`）。
   - 抽出 `internal/app/proc.go`：承接 `newTerminal`、`spawned`、`reexec`、`claim`、`adopt`、`activity`、`forget` 与 `shells`/`taken`。
   - 抽出 `internal/app/panes.go`（或保留精简 `tabs.go`）：标签 CRUD 与窗格切分/移动收敛在一处，不再横跨 `app.go` 与 `tabs.go`。

2. **统一浮层/模态互斥模型**
   - 文件：`internal/app/app.go`、`about.go`、`palette.go`、`find.go`、`confirm.go`、`tabs.go`
   - 做法：提供统一的 `closeOverlays(except ...)` 方法，在打开任一互斥浮层（重命名、确认框、关于、命令面板、查找栏、录制快捷键）时统一收口清理，去掉 `view()` 中每帧轮询 `Open` 标志位做二次置空的逻辑。

3. **清理 `settingsTab` 隐式时序与草稿耦合**
   - 文件：`internal/app/settings.go`、`internal/ui/settings.go`
   - 做法：
     - 将 `a.settings`（运行时已生效设置）与 `a.draft`（设置页编辑草稿）在语义上或更新入口上明确区分，避免 `ui` 层直接原地篡改未校验字段；
     - 为 UI 控件补全通过 `ui.Actions` 回传变更的路径，至少将触发副作用/联动校验的字段（如 `DefaultProfile`、`Theme`、`Language`、`MaxPanes`）收口到 `Actions`；
     - `closeSettingsTab` 改为幂等，不依赖 `refreshSettings` 的调用顺序。

4. **静态文案统一改用 `locales.*` typed accessor**
   - 文件：`internal/app/app.go`、`confirm.go`、`settings.go`、`advanced.go`、`about.go`、`palette.go`、`tabs_test.go`
   - 做法：将静态已知 key 的 `i18n.T(...)` / `i18n.F(...)` 替换为 `locales.SystemProfile()`、`locales.ErrSettings(...)` 等生成的强类型函数；同步把 `internal/ui/schemes.go:128-129` 的硬编码英文示例句纳入本地化或明确为字形预览。

## P2：渲染性能、UI 交互与配置校验

目标：消除每帧不必要的热路径分配与重算，补齐配置校验与输入边界。

1. **消除 `internal/ui` 每帧重算与分配**
   - `internal/ui/keybindings.go`：
     - 将 `changedActions`、`clashingKeys`、`groups` 改为仅在按键映射/搜索词/开关变化时重算并缓存；
     - 录制快捷键时不再每帧注册上千个 `OnWindowShortcut`，改为仅在进入录制状态时绑定或利用窗口级原始按键事件；`FormatKey` 改用预构建 map 替代每次重建 `KeyNames()` 切片。
   - `internal/ui/schemes.go` & `internal/ui/palette.go`：按搜索词与列表修订号缓存过滤/排序结果，避免每帧对 600+ 配色或全部命令做 `ToLower` + 排序；配色结果截断至 60 条时在界面给出“还有 N 项未显示”提示。
   - `internal/ui/tabs.go`：对 `measuredName` 按 `(name, fontFamily, fontSize)` 增加小型 LRU/Map 缓存，避免每帧对每个标签调用 `c.MeasureText`。

2. **修复 UI 交互细节缺陷**
   - `internal/ui/keys.go`：支持解析 `"ctrl++"` / `"plus"`（按最后一个非空 token 或显式映射处理 `+` 键）。
   - `internal/ui/form.go`：`choice()` 改为按索引或 `Value` 匹配，避免重名 Profile 时选中错误项。
   - `internal/ui/tabs.go`：拖拽放回原位（`d.from == i`）时不触发 `MoveTab`；优化 `stripTabs` 溢出箭头的可见性判定，消除边界宽度下的 1 帧抖动。
   - `internal/ui/keybindings.go` & `internal/ui/schemes.go`：固定“已更改”徽章占位与非自定义配色行右侧占位，保证按钮不发生水平位移；`DeleteAndRestart` 按钮改用 `inkOn(t.Danger)` 计算前景色。

3. **补全 `internal/store` 与 `internal/profile` 校验**
   - `internal/store/validate.go` & `internal/ui/settings.go`：
     - 将 `Font.Size`、`LineHeight`、`Padding`、`MaxPanes` 等范围常量下沉到 `store` 作为单一事实来源，UI 控件直接读取；
     - 补齐 `CursorShape`、`RightClick`、`NewTabPosition`、`TabWidth`、`StartOn` 的枚举校验（含 `rightClick: "copy"` 在 UI 下拉框的展示），以及 `Schemes` 颜色格式、`Keybindings` 键位可解析性校验。
   - `internal/store/settings.go`：将 `Default()` 的 `Schemes`、`Profiles` 初始化为非 nil 空切片 `[]`，避免序列化出 `null`；对未知字段至少在读取时记录日志告警（或保留原始未知字段 map 避免保存时静默丢失）。
   - `internal/profile/profile.go`：对重复 `ID` 或空 `ID` 给出明确诊断提示而非静默覆盖/丢弃；匹配到系统已发现 ID 时保留 `Discovered: true` 语义（避免用户手写同 ID 后误显示“删除”而非“隐藏”）。

## P3：跨平台健壮性、功能补齐与测试/CI

目标：补齐低覆盖率测试与 CI 盲区，完善跨平台边缘行为，并按 `docs/plan.md` 收尾未完成功能。

1. **跨平台与系统层加固（`internal/sys`）**
   - `internal/sys/shell_windows.go`：过滤 `docker-desktop`、`docker-desktop-data` 等非交互式 WSL 发行版。
   - `internal/sys/shell_other.go`：对环境变量 `$SHELL` 增加可执行性与非 `nologin`/`false` 校验。
   - `internal/sys/open_other.go` & `open_windows.go`：`xdg-open`/`open` 前加 `--` 防参数注入；Windows 使用 `%SystemRoot%\explorer.exe` 并释放子进程句柄；`relaunch_other.go` 补充 `cmd.Process.Release()`。
   - `internal/sys/redact.go` / `internal/cli/report.go`：Windows 下脱敏匹配改为大小写不敏感。
   - `internal/sys/crash.go`：使用 `O_EXCL` + 序号后缀避免同秒内多次崩溃覆盖日志。
   - `internal/sys/diagnose.go`：`NativeLibrary` 在读取 `MYGO_GHOSTTY_VT` 后校验文件真实存在（✅ 已做，见 `TestNativeLibraryEnv`）；`Tail` 改用 `io.ReadFull` / 循环读（未做）。
   - `internal/sys/relaunch_windows.go`：当因嵌套 Job 导致 `CREATE_BREAKAWAY_FROM_JOB` 报 `ERROR_ACCESS_DENIED` 时，回退为不带 breakaway 标志重试。

2. **补齐测试覆盖与 CI 矩阵**
   - `internal/app`（当前 46.4%）：为 `AddProfile`/`DuplicateProfile`/`SaveSettings`（含磁盘冲突）、`act` 动作分发、`closeOtherTabs`/`closePane`/`splitPane`、以及 `spawned`/`reexec`/`claim`/`forget` 并发竞态补充单元测试。
   - `locales/locales_test.go`（当前 1.0%）：增加对 `locales.In(lang)` 中所有 typed accessor 的调用冒烟，验证生成代码与 JSON 键、参数签名一致。
   - `.github/workflows/ci.yml`：在 `windows-latest` 与 `macos-latest` 评估开启 `-race`（若 cgo 可用），并在 `Scripts/build.ps1 -Test` 中加上 `-count=1`；`Scripts/build.sh` 改用更稳健的 JSON 解析提取版本。
   - `internal/cli/cli.go`：`wt-go version` 改用轻量的 `cli.About()`，避免触发全量 `Collect()` 系统扫描。

3. **按 `docs/plan.md` 收尾未实现功能（独立排期）**
   - **关于对话框（阶段 4.7）**：补充展示 `mygo` 版本、当前 `settings.json` 与 `wt-go.log` 路径（✅ 已做；`libghostty` 版本仍缺，由终端插件报告）；
   - **交互细节（阶段 4）**：实现 `Ctrl+Shift+滚轮` 调整窗口透明度、终端滚动条绘制与拖拽；
