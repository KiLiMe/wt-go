# 配置参考

`settings.json` 全字段、路径写法、数值范围与默认键位规范。操作说明见 [使用说明.md](使用说明.md)。

## 1. 文件位置与解析规则

- **位置**：安装版为 `%LOCALAPPDATA%\wt-go\settings.json`（Linux/macOS `~/.config/wt-go/settings.json`）；便携版（exe 旁存在 `data` 目录）为 `data\config\settings.json`。同目录的 `window-state.json` 记录窗口位置、尺寸与最大化状态（删掉后下次按 960×600 居中打开）。
- **读写与容错**：首次启动写入默认值，后台约每秒检查字节变化并热重载；写入采用临时文件 + 原子替换（保留权限与软链接）。
  - **JSON 错误或数值越界**：拒绝整份文件，保留当前生效配置，并将坏文件归档为 `settings.json.bad-<yyyyMMdd-hhmmss>`。
  - **枚举名写错**：不拒绝文件，仅该字段回落到默认值；`language` 非合法 BCP 47 回落跟随系统，合法但无译文（如 `fr-FR`）时保留配置并显示原文。
  - **未知顶层键**：读取时保留、保存时原样写回（已知内部对象如 `font` 内的额外键不保留）。

## 2. 示例

```json
{
  "language": "zh-Hans",
  "theme": "dark",
  "defaultProfile": "pwsh7",
  "startOn": "default",
  "startDirectory": "",
  "font": { "family": "monospace", "weight": 400, "size": 13, "lineHeight": 1.2 },
  "colorScheme": "Campbell",
  "padding": { "x": 12, "y": 8 },
  "backgroundOpacity": 1.0,
  "cursorShape": "bar",
  "cursorBlink": true,
  "scrollbackMB": 10,
  "newTabPosition": "last",
  "tabWidth": "compact",
  "alwaysOnTop": false,
  "titleFromActiveTerminal": false,
  "copyOnSelect": false,
  "rightClick": "copyOrPaste",
  "pasteMultilineConfirm": true,
  "confirmClose": "running",
  "closeOnLastTab": true,
  "confirmCloseWindow": true,
  "maxPanes": 4,
  "links": { "open": true },
  "schemes": [],
  "profiles": [
    {
      "id": "pwsh7",
      "name": "PowerShell 7",
      "command": "pwsh.exe",
      "args": ["-NoLogo"],
      "dir": "",
      "color": "#3b78ff",
      "icon": "",
      "hidden": false
    }
  ],
  "keybindings": [
    { "key": "ctrl+shift+t", "action": "tab.new" },
    { "key": "ctrl+shift+w", "action": "pane.close" }
  ]
}
```

## 3. 全字段

| 字段 | 默认 | 取值与说明 |
| --- | --- | --- |
| `language` | `""` | `""`（跟随系统）/ `zh-Hans` / `en`（BCP 47；兼容 `zh-CN`→`zh-Hans`、`en-US`→`en`） |
| `theme` | `dark` | `system` / `light` / `dark` / 任意配色方案名（仅控制窗口界面，活动标签随窗格） |
| `defaultProfile` | `""` | profile 的 `id`；空值、找不到或已隐藏时回落「跟随设备」（按 `pwsh7→powershell→bash→cmd→nu→wsl:*` 取首个实测 shell） |
| `startOn` | `default` | `default`（按 `defaultProfile`）/ `new`（强制用设备默认 shell 开首个标签）；`restore` 尚未实现 |
| `startDirectory` | `""` | 新标签起始目录：`""` / `home`（主目录）、`current`（进程启动 cwd）或路径；profile 的 `dir` 优先 |
| `font` | `monospace` 400 13 1.2 | `family`（逗号分隔，空串自动补 `monospace`）、`weight`（100–900，粗体由框架按 `+300` 且 `≥700` 派生）、`size`、`lineHeight` |
| `colorScheme` | `Campbell` | 自定义 `schemes` > 内置 7 套（Campbell / Campbell Powershell / Solarized Dark/Light / Tango Dark/Light / Vintage）> Ghostty 617 套 |
| `padding` | `{12, 8}` | 终端网格四周留白（DIP）；**新标签生效** |
| `paddingColor` | `background` | `background` / `extend` / `always`；**新标签生效** |
| `minimumContrast` | `0` | WCAG 最低对比度（0–21，4.5 为可读线） |
| `backgroundOpacity` | `1.0` | 窗口不透明度（`0.3`–`1`） |
| `cursorShape` | `bar` | `bar` / `block` / `underline`；**新标签生效** |
| `cursorBlink` | `true` | 光标闪烁；**新标签生效** |
| `scrollbackMB` | `10` | 回滚缓冲大小（MB）；**新标签生效** |
| `newTabPosition` | `last` | `last` / `first` |
| `tabWidth` | `compact` | `compact`（按名夹在 116–240 DIP）/ `equal`（均分夹在 116–240 DIP）；溢出时横向滚动 |
| `alwaysOnTop` | `false` | 窗口置顶（Wayland 受合成器限制可能无效） |
| `titleFromActiveTerminal` | `false` | 窗口标题随当前焦点窗格变化 |
| `copyOnSelect` | `false` | 选中即复制 |
| `scrollMultiplier` | `1` | 滚轮与触控板步进倍数 |
| `clipboardRead` | `deny` | `deny` / `allow` / `ask`；**新标签生效** |
| `clipboardWrite` | `allow` | `allow` / `deny`；**新标签生效** |
| `rightClick` | `copyOrPaste` | `copyOrPaste` / `paste` / `copy` / `menu` / `nothing`；**新标签生效** |
| `links` | `{"open":true}` | `open`：是否启用悬停下划线/手型提示与点击打开（即时生效） |
| `pasteMultilineConfirm` | `true` | 多行粘贴前确认 |
| `confirmClose` | `running` | `running`（进程树有子进程或无法判断时询问）/ `always` / `never`（兼容读取旧布尔值 `true`/`false`） |
| `closeOnLastTab` | `true` | 关掉最后一个标签时退出窗口 |
| `confirmCloseWindow` | `true` | 窗口存在 ≥2 个标签时关闭前询问 |
| `maxPanes` | `4` | 单标签窗格上限（`0` 为不限） |
| `schemes` | `[]` | 自定义配色：`name`、`background`、`foreground`、`cursor`、`selection`、`palette`（16 色数组） |
| `profiles` | 首次探测结果 | `id`、`name`、`command`（空＝系统默认 shell）、`args`、`dir`、`color`、`icon`、`hidden`、`discovered` |
| `keybindings` | 动作目录默认值 | `[{key, action}]`；文件一旦声明则全量取代默认键位 |

## 4. 数值校验范围

保存或热重载时超出以下范围将拒绝整份配置：

- `font.size`：`4`–`200`；`font.weight`：`100`–`900`（`0` 补为 `400`）；`font.lineHeight`：`0.5`–`4`
- `padding.x` / `padding.y`：`0`–`256`
- `backgroundOpacity`：`0.3`–`1`
- `scrollbackMB`：`0`–`1024`
- `scrollMultiplier`：`0.1`–`10`
- `minimumContrast`：`0`–`21`
- `maxPanes`：`0`–`64`

## 5. 路径解析与关闭确认细节

- **路径保留词与展开**：`startDirectory` 与 `profiles[].dir` 均认 `current`（进程启动 cwd，非 `PWD`）与 `home`（`os.UserHomeDir()`）；真实同名目录需写成 `./current`。其余值支持开头 `~` 及 `%NAME%` / `$NAME` / `${NAME}` 环境变量（未定义变量原样保留，便于暴露写错的路径）。
- **目录优先级**：复制标签（`Ctrl+Shift+D`）直接沿用当前窗格目录；其余情况按 `profiles[].dir` → 命令行 `-d` → `startDirectory` → `home` 顺序解析。
- **字体回落**：`font.family` 为逗号分隔列表，取第一个已安装族；若首个已安装族非等宽，终端改用 `monospace` 并记录 `E204`（不弹窗）。
- **关闭确认（`confirmClose`）**：按 shell 进程树（并下探 Scoop 等启动器 shim）判断是否有外部子进程；shell 内置命令不产生子进程故不触发。已退出的标签直接关闭；若无法读取进程表（`E303`）或未认出 shell（`E304`），会提示“无法判断是否有程序在运行”。

## 6. 默认键位与 `keybindings` 写法

动作 id、标题与默认键位唯一来源为 `internal/action/action.go`。

### 默认键位表

| 分组 | 键 | 动作 id | 说明 |
| --- | --- | --- | --- |
| Tab | `Ctrl+Shift+T`、`Ctrl+T` | `tab.new` | 新建标签 |
| Tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` | `tab.next` / `tab.prev` | 下一个 / 上一个标签（支持连发） |
| Tab | `Ctrl+Shift+D` | `tab.duplicate` | 复制当前标签 |
| Tab | `Ctrl+1`…`Ctrl+9` | `tab.goto.N` | 切到第 N 个标签 |
| Tab | `Ctrl+Shift+1`…`Ctrl+Shift+9` | `profile.N` | 用第 N 个可用 profile 新建标签 |
| Tab | （无） | `tab.close` | 关闭标签 |
| Pane | `Alt+Shift+D` | `pane.split.auto` | 自动切分（先竖后横） |
| Pane | `Alt+Shift+Right` / `Alt+Shift+Down` | `pane.split.right` / `pane.split.down` | 纵向 / 横向切分 |
| Pane | `Alt+左/右/上/下` | `pane.focus.left` / `right` / `up` / `down` | 移焦点到相邻窗格（支持连发） |
| Pane | `Ctrl+Shift+W` / `Alt+Shift+W` | `pane.close` / `pane.closeOthers` | 关闭窗格 / 关闭其它窗格 |
| Find | `Ctrl+Shift+F` | `find.open` | 打开查找栏 |
| Window | `Ctrl+,` / `Ctrl+Shift+P` | `settings.open` / `palette.open` | 打开设置 / 命令面板 |
| Window | （无） | `about.open` | 打开「关于」（可从 `▾` 菜单、命令面板打开或自录快捷键） |

终端插件内置快捷键（未经 `keybindings`，由 `mygo/plugins/terminal` 直接处理）：`Ctrl+Shift+C` / `Ctrl+Insert`（复制）、`Ctrl+Shift+V` / `Shift+Insert`（粘贴）、`Ctrl+Shift+A`（全选）、`Ctrl+C`（有选区复制，否则发给程序）、`Ctrl+滚轮`/`=`/`-`/`0`（字号缩放重置）、`Ctrl+Shift+K`（清屏）、`Shift+PageUp/PageDown`（翻页）、`Ctrl+Shift+Home/End`（滚到顶/底）、`F11` / `Alt+Enter`（全屏）、`Ctrl+Shift+Space`（下拉菜单）。

### `keybindings` 规则与键名语法

- **全量覆盖**：`settings.json` 一旦包含 `keybindings`，默认值即全部失效（不会自动合并新版新增默认键；需恢复可在设置页「快捷键」点重置或删除该字段）。
- **多键与透传**：同一 `action` 写多条即绑定多个键（设置页录制新键会替换该动作所有旧键）；要将默认快捷键让给终端内程序，需从数组里删除该条。写错的条目仅丢弃该条并记 `E203`（不回退默认键）；未知 `action` 仍可能拦截按键。
- **键位字符串（不区分大小写）**：`修饰键+…+键名`
  - **修饰键**：`ctrl`（`control`）、`shift`、`alt`、`win`（`super`、`meta`、`cmd`、`command`）
  - **键名**：`a`–`z`、`0`–`9`、`f1`–`f12`、`tab`、`enter`（`return`）、`escape`（`esc`）、`space`、`backspace`、`delete`（`del`）、`insert`（`ins`）、`home`、`end`、`pageup`（`pgup`）、`pagedown`（`pgdn`）、`up`、`down`、`left`、`right`、`minus`、`equal`、`comma`、`period`、`slash`、`semicolon`、`quote`、`backslash`（暂不支持 `plus` 与 `f13+`）。
