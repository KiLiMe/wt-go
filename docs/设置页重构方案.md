# 设置页重构方案

> 本文档定义 `wt-go` 设置页（`internal/ui/settings.go` 及相关模块）的彻底重构方案与分步实施清单，按 **S1–S6** 逐条由子代理实现并验收。当前进度：**S1–S5 已完成**，S6 待执行。

## 1. 重构目标与设计原则

1. **按用户心智域划分，而非历史拼凑**：左侧一级导航固定为 **6 项**，不再将 `Profile:*` 平铺在一级菜单中导致导航膨胀。
2. **外观所见即所得**：将“应用主题 + 透明度 + 字体/字号/行高 + 内边距 + 光标 + 最小对比度 + 配色方案”统一收口到 **外观与排版 (`Appearance`)**，顶部提供实时联动预览区。
3. **生命周期与交互边界清晰**：将分散在 Startup / Appearance / Interaction 中的窗口、标签页、分屏与关闭确认收口到 **常规与启动 (`General`)**；将鼠标、剪贴板安全与缓冲收口到 **终端与交互 (`Terminal & Input`)**。
4. **Profile 主从管理**：**配置文件 (`Profiles`)** 采用页内 Master-Detail（主从两栏）布局，列表选择、搜索、显示已隐藏、新建/复制/删除/编辑全部在同一视图内完成。
5. **底栏职责纯粹**：底栏**最左侧**为「打开设置文件」（直接打开 `settings.json`），中间显示未保存/校验状态提示，**最右侧**为「放弃更改」与「保存」。
6. **全局可搜索**：左侧导航顶部提供全局设置搜索框，支持跨页面检索设置项并跳转定位。

## 2. 新导航结构与字段归属

### 左侧一级导航（固定 6 项 + 顶部全局搜索）

| 导航项 | Page ID | 涵盖设置项与功能 |
| --- | --- | --- |
| **常规与启动** | `general` (兼容原 `startup`) | **语言与启动**：界面语言 (`Language`)、默认 Profile (`DefaultProfile`)、默认起始目录 (`StartDirectory`)<br>**窗口与标签页**：新标签位置 (`NewTabPosition`)、标签宽度 (`TabWidth`)、标题跟随活动终端 (`TitleFromActiveTerminal`)、置顶显示 (`AlwaysOnTop`)、每标签最大窗格数 (`MaxPanes`)<br>**关闭行为**：关闭最后一个标签时关闭窗口 (`CloseOnLastTab`)、关闭标签/窗格确认 (`ConfirmClose`)、关闭窗口确认 (`ConfirmCloseWindow`) |
| **外观与排版** | `appearance` | **实时终端预览区**：即时联动当前字体家族、字号、行高、内边距、填充色、光标形状/闪烁、最小对比度、配色方案与背景透明度<br>**应用外观**：UI 主题 (`Theme`)、背景透明度 (`BackgroundOpacity`)<br>**字体与排版**：字体家族 (`Font.Family`)、终端字体大小 (`Font.Size`)、行高 (`Font.LineHeight`)、内边距 (`Padding.X/Y`)、内边距填充色 (`PaddingColor`)<br>**光标与对比度**：光标形状 (`CursorShape`)、光标闪烁 (`CursorBlink`)、最小对比度 (`MinimumContrast`)<br>**配色方案**：方案下拉选择 + 搜索过滤 + 方案列表（切换/复制为自定义/删除） |
| **终端与交互** | `interaction` | **鼠标与滚动**：选中即复制 (`CopyOnSelect`)、右键行为 (`RightClick`)、滚轮倍率 (`ScrollMultiplier`)<br>**剪贴板与安全**：读取剪贴板 (`ClipboardRead`)、写入剪贴板 (`ClipboardWrite`)、多行粘贴确认 (`PasteMultilineConfirm`)<br>**缓冲区**：回滚历史大小 (`ScrollbackMB`) |
| **配置文件** | `profiles` | **Master-Detail 主从两栏**：<br>• 左侧列表：搜索框、`+ 新建配置文件`、全部 Profile 列表（含“内置”与“已隐藏”徽章；隐藏项照常列出且可点开，ADR-71）<br>• 右侧详情：选中 Profile 的名称、命令行（内置只读提示 / 自定义可编辑+空命令回退提示）、参数、起始目录（含默认目录继承提示）、图标、图标颜色、隐藏开关、复制、隐藏（内置只有它）/ 删除（自己写的） |
| **快捷键** | `actions` | 分组快捷键列表、搜索过滤、仅看已修改、冲突检测提示、按键录制、恢复默认快捷键 |
| **高级与系统** | `advanced` | **Shell 探测**：重新探测本机 Shell (`AskRediscover`)<br>**文件夹与诊断**：打开设置目录 (`OpenSettingsFolder`)、打开程序目录 (`OpenProgramFolder`)<br>**危险操作**：删除设置并重启 (`AskReset`) |

### 底部操作栏（Footer）布局

`[ 打开设置文件 ]`  `<--- 状态提示（Note / SaveRefusedNote / UnsavedChanges） --->`  `[ 放弃更改 ] [ 保存 ]`

- 最左侧：`OpenSettingsFile`（打开 `settings.json` 文件，若不存在则先写出默认配置或打开所在目录提示）
- 最右侧：`DiscardSettings`（次按钮，无改动禁用）、`SaveSettings`（主按钮，无改动禁用）

## 3. 分步实施清单（供子代理逐条执行与验收）

| 步骤 | 目标 | 涉及模块 | 验收标准 |
| --- | --- | --- | --- |
| **S1** | 新增 `OpenSettingsFile` 并重构底栏布局 | `internal/sys`、`internal/app`、`internal/ui`、`locales` | 点击“打开设置文件”可调用 `OpenSettingsFile`；底栏最左为打开设置文件，最右为放弃更改与保存；`i18n check` 与单测通过 |
| **S2** | 重构导航骨架与 `General`、`Terminal & Input` 页面 | `internal/ui/settings.go`、`internal/app/settings.go`、`locales` | 左侧固定 6 项导航，所有设置项归位到 `General` 与 `Interaction`，无丢失字段；旧 Page ID 兼容不 panic |
| **S3** | 重构 `Appearance`（合并排版+配色+实时终端预览区） | `internal/ui/settings.go`、`internal/ui/schemes.go`、`locales` | 字体/字号/行高/光标/Padding/配色方案全部在 `Appearance` 页，顶部预览区随参数联动绘制 |
| **S4** | 重构 `Profiles` 为页内 Master-Detail 主从两栏 | `internal/ui/settings.go`、`internal/app/settings.go`、`locales` | 一级导航不再平铺 `Profile:*`；新建/复制/删除/隐藏/编辑全部在 `Profiles` 页内完成且测试通过 |
| **S5** | 增加左侧顶部「全局设置搜索框」与 `docs/` 同步 | `internal/ui/`、`internal/app/`、`docs/`、`locales` | 输入关键词可跨页面检索设置项并点击跳转到对应页面；文档与 `locales` 同步 | ✅ 已完成：`ui.Settings.Search`、`App.settingsSearch`、`settingsIndex()`、`searchSettingsIndex()`；切换页面时清空搜索 |
| **S6** | 全量测试、跨平台 `go vet` 与本地构建验证 | 全仓库 | `go tool mygo i18n check`、`go vet ./...`、`GOOS=linux go vet`、`go test -count=1 ./...` 与 `Scripts/build.ps1` 全部通过 |
